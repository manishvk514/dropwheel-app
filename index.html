DropWheel is a free Mac menu-bar app. While you drag any file, tap a key and a wheel appears at your pointer: convert it, edit it, compress it, AirDrop it. The result is saved beside the original.

Free · Apple silicon & Intel · macOS 13 Ventura or later · latest version

Three wheels, one gesture

Start dragging any file from Finder or your desktop, then tap one key. Move onto a petal and let go. Esc cancels.

⇧ Shift — Convert

275 conversions between 45 formats: photos, audio, video, PDF, Word, Pages, Markdown, slides, spreadsheets, subtitles and archives.

⌘ Command — Tools

Compress, metadata, edit, annotate, crop and redact photos; trim, normalize and bleep audio; trim, crop, speed up, split and join video; organize and merge PDFs.

⌃ Control — Actions

AirDrop, keep it on the Float shelf, copy, move, copy the path, or open the folder in Terminal. Works for folders too.

Install

Two ways. Pick one.

A · Download the app

  1. Click Download for Mac and open DropWheel.dmg.
  2. Drag DropWheel onto the Applications folder in that window.
  3. Open DropWheel from Applications. The first time, macOS says it can't check the app for malicious software — click Done.
  4. Open System Settings → Privacy & Security, scroll down, and next to “DropWheel was blocked” click Open Anyway, then confirm. You only do this once.

B · One line in Terminal

Downloads the latest version, puts it in Applications and opens it — no security prompt. Run it again any time to update.

curl -fsSL https://manishvk514.github.io/dropwheel-app/install.sh | bash

Open Terminal (⌘ Space, type “Terminal”), paste, press Return. You can read the script first.

Why the warning in option A? DropWheel is free and not sold through the App Store, so it isn't notarized by Apple (that needs a paid developer account). It runs entirely on your Mac and never connects to the internet.

Turn on every conversion

Photos, PDFs and text work straight away. Video, audio, Office files and e-books use free, open-source engines (FFmpeg, Pandoc, LibreOffice, Calibre and friends) that DropWheel installs for you with Homebrew.

  1. Install Homebrew if you don't have it: follow the one-line instruction on brew.sh.
  2. Click DropWheel's icon in the menu bar → Engines… → Install Missing… and wait for it to finish.
  3. Optional: for .pages files, get Apple's free Pages app.

Everything included

Questions

Is it really free?

Yes. No trial, no limits, no account.

Which Macs does it run on?

Any Mac with Apple silicon (M1 and later) or an Intel processor, running macOS 13 Ventura or later. It's one universal app.

Where do the converted files go?

Next to the original, named like “photo.webp” or “photo Compressed.jpg”. You can choose a fixed folder in Settings instead.

How do I update?

Download the latest DMG and replace the app, or run the one-line installer again.

How do I uninstall?

Quit it from the menu bar icon, then drag DropWheel from Applications to the Bin. To remove its engine helpers too, delete ~/Library/Application Support/DropWheel.
